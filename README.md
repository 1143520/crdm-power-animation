# 控制棒驱动机构电源（机组式）工作原理动画

纯静态 HTML/SVG 动画，讲解压水堆**控制棒驱动机构电源（机组式 M-G 机组）**的工作过程。

## 内容章节

1. 系统组成：电动机 — 飞轮 — 交流发电机 — 母线 — 逻辑柜 — CRDM 三组线圈
2. 机组启动：厂用电投入、升速、建压
3. 保持线圈 S 得电，抓住驱动杆
4. 移动线圈 M 得电，移动爪挂入下一齿
5. 提升线圈 L 得电，驱动杆上提一个齿距（约 10 mm）
6. 倒手：M、L 依次释放，完成一步
7. 失电：厂用电失去，飞轮惯性维持输出，控制棒保持原位
8. 落棒停堆：三组线圈断电，爪失磁，控制棒重力落入堆芯，缓冲器吸能
9. 小结：靠旋转惯量抵御短时失电，靠失磁落棒保证停堆安全

## 使用

直接用浏览器打开 `index.html`，或用任意静态服务器托管。

播放控制：暂停/播放、上一章/下一章、拖动进度条、点击底部色块跳章。

## 说明

动画为**原理示意**，时序与比例经过简化，用于理解流程；实际机组的转速、维持时间、步距以设计文件为准。
